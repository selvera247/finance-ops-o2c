# Value-capture checkpoint (OCFO)

**Purpose:** Prove measured change from baseline → post-launch (or mid-pilot). Lightweight enough for every engagement.  
**Upstream:** Discovery §7 + [handoff](./ocfo-handoff-package-template.md) §6.  
**Rule:** No checkpoint without a written baseline and agreed definitions.

**Assumptions**
- Pilot window ≥ 2 weeks of live use unless sponsor agrees to a shorter gate.
- Labor $ is optional; prefer time, quality, and cash-cycle proxies first.
- AI quality, user value, and business impact are separate layers—don’t collapse into one vanity metric.
